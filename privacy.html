2. Grundsatz der Datenverarbeitung

Sparring Timer wurde so entwickelt, dass die App ohne Registrierung, Benutzerkonto und ohne Übermittlung persönlicher Trainings- oder Nutzungsdaten an den Entwickler verwendet werden kann.

Die App verwendet keine Werbung, keine Analyse- oder Tracking-Dienste und keine Social-Media-Integrationen. Die für die Timer-Funktionen benötigten Einstellungen werden lokal auf dem Gerät verarbeitet.

3. Lokal gespeicherte Einstellungen und Presets

Sparring Timer speichert Einstellungen lokal auf dem Gerät, damit sie beim nächsten Start wieder zur Verfügung stehen. Dazu können insbesondere gehören:

  • Rundendauer und Pausendauer
  • Anzahl der Runden
  • Einstellungen des Random-Modus einschließlich Mindest- und Maximalzeit
  • Countdown-Einstellungen für Start, Runde und Pause
  • Sound- und Vibrationseinstellungen
  • Einstellung zur vorübergehenden Absenkung anderer Audio-Wiedergaben
  • gespeicherte Presets und das aktuell ausgewählte Preset
  • Verweise und Namen vom Nutzer ausgewählter eigener Sounds

Diese Einstellungen werden von Sparring Timer nicht an den Entwickler oder an eigene externe Server übertragen.

4. Eigene Sounds und Audiodateien

Neben den in der App enthaltenen Sounds können Nutzer eigene Audiodateien für Timer-Ereignisse auswählen, zum Beispiel für Rundenbeginn, Rundenende, Countdown oder Trainingsende.

Die Auswahl erfolgt über die von Android bereitgestellte Dateiauswahl. Sparring Timer speichert für die weitere Verwendung lokale Verweise auf die ausgewählten Dateien sowie deren Namen. Die Audiodateien werden nicht auf einen Server des Entwicklers hochgeladen und nicht an den Entwickler oder Dritte übertragen.

5. Audio-Fokus und „Musik leiser“

Ist die Funktion „Musik leiser“ aktiviert, kann Sparring Timer während eigener Timersignale den Android-Audiofokus verwenden. Dadurch kann die Wiedergabe einer anderen Audio-App vorübergehend abgesenkt und anschließend wieder freigegeben werden.

Sparring Timer erhält dadurch keinen Zugriff auf Wiedergabelisten, Kontoinformationen oder sonstige Inhalte der anderen Audio-App.

6. Vibration

Auf Wunsch ergänzt die App Timersignale durch Vibrationssignale. Die dafür verwendete Vibrationsberechtigung dient ausschließlich der haptischen Rückmeldung. Hierbei werden keine personenbezogenen Daten an den Entwickler übertragen.

7. Benachrichtigungen und Hintergrundbetrieb

Damit ein vom Nutzer gestarteter Timer auch bei gesperrtem Bildschirm oder während der Nutzung einer anderen App zuverlässig weiterlaufen kann, verwendet Sparring Timer einen Foreground Service.

Während eines laufenden Trainings kann Android eine Benachrichtigung mit dem aktuellen Timerstatus und Bedienelementen anzeigen. Je nach Timerzustand kann der Timer darüber beispielsweise pausiert, fortgesetzt oder beendet werden.

Die hierfür verarbeiteten Timerinformationen werden lokal auf dem Gerät verwendet und nicht an den Entwickler oder eigene externe Server übertragen.

8. Internetverbindung

Für die grundlegenden Funktionen von Sparring Timer ist keine Internetverbindung erforderlich. Die App fordert keine Android-Internetberechtigung an und überträgt keine Timer-Einstellungen, Presets oder Trainingsdaten an eigene externe Server.

9. Bluetooth-Lautsprecher und Kopfhörer

Die Audioausgabe kann über die von Android aktuell verwendete Audioausgabe erfolgen, beispielsweise über bereits verbundene Bluetooth-Lautsprecher oder Kopfhörer.

Sparring Timer fordert keine Bluetooth-Berechtigung an, sucht nicht selbst nach Bluetooth-Geräten und liest keine Bluetooth-Gerätelisten aus.

10. Werbung, Analyse und Tracking

Sparring Timer verwendet keine:

  • Werbenetzwerke
  • Tracking-Dienste
  • Analyse-Tools wie Firebase Analytics
  • Crash-Reporting-Dienste von Drittanbietern
  • Social-Media-Tracking- oder Login-SDKs

11. Weitergabe von Daten

Sparring Timer übermittelt keine persönlichen Trainings- oder Nutzungsdaten an den Entwickler. Eine Weitergabe solcher Daten durch den Entwickler an Dritte findet daher nicht statt.

12. Android-Backup

Die App erlaubt grundsätzlich die Nutzung der Android-Backup-Funktion. Abhängig von den Geräteeinstellungen, der Android-Version und den für die App geltenden Backup-Regeln können lokal gespeicherte App-Daten durch das Betriebssystem gesichert oder auf ein neues Gerät übertragen werden.

Ein solches Backup wird durch Android bzw. den vom Nutzer verwendeten Betriebssystem-/Backup-Dienst verwaltet und nicht durch einen eigenen Server von Sparring Timer.

13. Löschung lokal gespeicherter Daten

Einzelne Presets können innerhalb der App gelöscht werden. Weitere lokal gespeicherte App-Daten können über die Android-Systemeinstellungen durch Löschen der App-Daten oder durch Deinstallation der App entfernt werden.

Diese Datenschutzerklärung wird angepasst, wenn neue Funktionen hinzukommen, sich die Datenverarbeitung ändert oder eine Aktualisierung aus rechtlichen oder technischen Gründen erforderlich wird. Auf dieser Seite wird jeweils die aktuelle Fassung veröffentlicht.
